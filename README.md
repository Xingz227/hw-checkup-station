# 外设体检站

新键盘、新屏幕、二手配件到手——花三分钟，给它做个体检。

**在线体验**：https://xingz227.github.io/hw-checkup-station/

## 能检什么

### ⌨️ 键盘体检
- 104 键位可视化：按过的键实时点亮、计数
- 实时 keycode 显示（`event.code`，不受输入法/布局影响）
- 无冲测试：同时按住尽可能多的键，统计最大同时响应数
- 连击检测：同一键两次「按下—松开」间隔 < 250ms 自动标红
- 卡键检测：按住时切走窗口、回来仍未收到松开信号，自动标黄
- 事件日志：逐条显示按下 / 松开 / 重复信号

### 屏幕体检
- 9 种纯色图案测坏点：点击屏幕即可标记可疑点（记录百分比坐标）
- 32 级灰阶（看色带断层）、彩色渐变、网格（摩尔纹 / 清晰度）
- UFO 响应测试：480 / 960 / 1440 px/s 三档，看轮廓拖影
- 文字清晰度：多字号中文 + 西文混排样本

### 体检报告
- 自动汇总键盘覆盖、无冲、连击、卡键、坏点标记
- 一键复制纯文本报告

## 技术

- 纯前端单文件 `index.html`，零外部请求、零依赖，双击即用
- 数据只存在浏览器内存 / localStorage，不上传
- 已经 Playwright headless 26 项冒烟测试全覆盖（键盘事件、无冲、连击、卡键、坏点标记、图案切换、报告生成）

## 本地运行

直接双击 `index.html`，或：

```bash
python3 -m http.server 8000
# 打开 http://localhost:8000
```
